今回のセットでは回答の改善は観測できなかった。原記憶が各ケース2件と短く、現行方式で
既に根拠をすべて取得できる。Atomic Factも原文と同じ本文なので、意味単位の抽出・圧縮や
難しい検索での利点を評価できない。検索時間は一回のローカル測定であり、一般的な性能を
表すベンチマークではない。

回答したAIは先に正解を読んでおり、採点も同じAIが行った。この32件は**非盲検の予備評価**
であり、独立した正答率推定や因果的な効果測定ではない。モデルの固定版、temperature、seedは
この接続から確認できない。実回答・配信文脈・引用ID・判定理由・測定値は

## 独立評価

`node scripts/run-memory-index-answer-evaluation.mjs` は正解・方式名を除いた32個の回答
プロンプトを準備する。`--run` は既存Codex認証を使い、新しい空の読み取り専用ディレクトリ
で各回答を生成する。ツール・メモリ・プラグインを無効にし、観測されたツール呼び出しや
不明・変更されたモデルIDを拒否する。正誤フィールドは根拠照合までnullのまま。

今回の独立AI呼び出しはユーザーの許可回答を待っており、まだ実行していない。
非盲検の予備評価を独立評価の結果として扱わない。
